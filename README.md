API бот, подключаемый к вашему личному аккаунту через встроенную в Telegram функцию **«Чат-боты»**
(Settings → Telegram Business → Чат-боты). Сохраняет входящие сообщения
и при их удалении присылает копию вам в личку с ботом.

## Как это работает

Telegram Business API присылает боту специальные апдейты:
- `business_message` / `edited_business_message` — сообщения в чатах
  бизнес-аккаунта, к которому подключён бот;
- `deleted_business_messages` — сообщения удалили, но **в апдейте только
  ID**, без текста.

Поэтому бот заранее сохраняет все входящие бизнес-сообщения в SQLite, а
при удалении достаёт сохранённую копию и шлёт её вам отдельным
уведомлением.

## Ограничения (важно)

- Нужна подписка с функциями **Telegram Business** на том аккаунте,
  который вы мониторите (это платная функция Telegram Premium/Business).
- Работает **только для личных чатов (1-на-1)** — так устроен сам API,
  групповые чаты не поддерживаются.
- Видит удаление только тех сообщений, которые сами успели получить и
  сохранить (т.е. пришедших после подключения бота).
- Если вы хотите мониторить свой собственный диалог с кем-то — помните,
  что это фактически скрытое логирование переписки. Используйте только
  там, где у вас есть на это право по закону и перед собеседником.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

### 1. Создать бота

Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, впишите
полученный токен в `BOT_TOKEN` в `.env`.

### 2. Запустить бота

```bash
python main.py
```

### 3. Привязать себя как владельца

В Telegram напишите своему боту `/start` **с того аккаунта**, который
будете мониторить. Бот запомнит ваш `user_id` (сохранит в `state.json`)
и будет слать уведомления именно туда. Либо впишите свой `user_id`
заранее в `OWNER_ID` в `.env` (узнать id можно через
[@userinfobot](https://t.me/userinfobot)).

### 4. Подключить бота как чат-бота Business

На аккаунте, который мониторите:
**Настройки → Telegram Business → Чат-боты** → выбрать вашего бота →
включить права, как минимум **«Читать сообщения»**.

После этого все новые входящие/исходящие сообщения в ваших личных чатах
начнут логироваться, а при удалении любого из них бот пришлёт вам в
личку карточку вида:

```
🗑 Удалено сообщение
Чат: Иван Иванов (@ivan)
От: Иван Иванов (@ivan)
Отправлено: 2026-10-20 14:03:11 UTC

текст удалённого сообщения
```

Если в удалённом сообщении было медиа (фото/видео/голосовое/файл/стикер)
— оно будет переслано вместе с карточкой.

## Структура проекта

- `main.py` — бот на aiogram 3: обработчики `business_message`,
  `edited_business_message`, `deleted_business_messages`.
- `storage.py` — SQLite-хранилище + простое хранилище owner_id в
  `state.json`.
- `.env.example` — шаблон конфигурации.
- `messages.db` — Файл базы данных куда сохраняются удаленные сообщения.

## Команды бота

- `/start` — привязать текущий аккаунт как владельца уведомлений.
- `/status` — показать текущий `owner_id` и ваш `user_id`.

## Деплой

Для постоянной работы разверните на VPS и запускайте через `systemd`,
`pm2`, `screen`/`tmux` или в Docker-контейнере — скрипт держит соединение
через `long polling`, вебхук не обязателен.
